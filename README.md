# realtime-transfer-check（リアルタイム乗り換え確認アプリ）

経路を複数登録して 1 つを選択し、「今いる場所」から徒歩＋乗り換え＋安全余裕を差し引いて、今から歩いて乗れる電車を 1 秒ごとに再計算して表示するアプリです。
個人の徒歩実績を学習して徒歩時間を補正したり、路線の運行情報（遅延）を取り込んだり、GPS で残り徒歩を補正したりできます。

## ⚠️ clone しただけでは動きません

このリポジトリは Muse の「スペース」のソースコードのミラーです。
動かすには、リポジトリに含まれていない **SDK・DB・ランタイムサービス** の補完が必要です。

**まず [GUIDE.md](GUIDE.md) を読んでください。** 不足しているものの一覧と、復元／移植の手順をまとめています。

要点だけ：

- `@hatch/space-sdk` は Muse 環境内のローカルファイルを指すため、外では `bun install` が失敗します
- DB（`app.db`）は含まれていません。`drizzle/` のマイグレーションから空で再作成できます
- 運行情報の取得はランタイム提供の Web 検索／推論（`ctx.*`）に依存しています
- 画像アセット不足でビルドが止まることはありません（アイコンは SVG 同梱）

## 構成

- `client/` — React クライアント（発車標ボード、経路エディタ、徒歩学習、GPS 補正）
- `client/src/lib/predict.ts` — 乗れる電車の予測計算（ランタイム依存なし）
- `server/src/actions.ts` — サーバーアクション（経路、徒歩実績、手動遅延、運行情報の更新）
- `server/src/schema.ts` / `drizzle/` — SQLite スキーマとマイグレーション
- `DATA-PLAN.md` — データ取得方針と情報源の詳細
- `GUIDE.md` — セットアップガイド
